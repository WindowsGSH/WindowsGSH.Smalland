# Security policy

## Security and trust

This module executes with the same Windows permissions as WindowsGSH. Review modified module source before loading it; WindowsGSH cannot guarantee arbitrary third-party packages.

## Download modules safely

Use the official WindowsGSH.Smalland repository or another source you explicitly trust. Verify release origin and changed executable source.

## Protect credentials and server data

Passwords, Epic Online Services values, player data, logs and backups are sensitive. Restrict filesystem access and never publish unredacted configuration, scripts, logs or archives.

## Report a vulnerability

Use the [private repository advisory page](https://github.com/WindowsGSH/WindowsGSH.Smalland/security/advisories/new). Do not publish exploits or credentials in a public issue.

## Include in a report

Include affected versions, module source, reproduction steps and sanitized diagnostics. Remove passwords, EOS values, player identifiers and public addresses.

## Supported versions

Security fixes target the current module release unless stated otherwise. Upgrade before reporting an already-resolved issue.
